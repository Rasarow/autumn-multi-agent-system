# Roles and decision rights
Planner proposes a retrieval query and complexity estimate. Researcher invokes the two approved read tools.
Writer selects verbatim evidence. Verifier independently checks relevance and completeness; deterministic checks enforce quotation provenance.
The supervisor alone chooses graph transitions, model tiers, budgets, and the final response.
Maximum five model calls, one repair, four evidence sections, and four claims per request.
No role can run a shell, fetch an arbitrary URL, or write a fact into the knowledge corpus.
